IDLE — Python editor and shell

IDLE is the integrated development environment that comes with Python. It is written in Python with the tkinter GUI toolkit and works the same on Windows, macOS and Unix.

  • A shell window: an interactive interpreter with colorized code, input and output and error messages.
  • Editor windows with undo, syntax coloring, smart indentation, call tips, completions and many more conveniences.
  • Search and replace in a window, and search in many files.
  • A debugger with breakpoints, stepping and views of the namespaces.
  • Settings dialogs, browsers of modules and of sys.path.

Menus

The shell and the editor windows have menus for the commands below (the shell has a Shell and a Debug menu, editors a Format and a Run menu). Most commands have a key binding, shown next to the item; the bindings can be changed in the settings.

Write the window to its file, to another file (which becomes the window's file), or to another file without changing the window.

Editing and navigation

The cursor keys, Home, End and the mouse work as usual. Home goes to the first non-blank character of the line, pressed again to the start of the line. In the shell, the input starts after the prompt.

After a line ending with a colon, Return indents the next line one level; after return, pass and similar statements, it dedents. Backspace in the indentation deletes one level. Inside brackets, the continuation lines are aligned with the opening bracket.

Completions open after a dot or a quote in a string (for file names), after a short delay, or with the Show Completions command. Tab completes, Escape closes the list.

The shell

Statements typed at the >>> prompt run when complete. Return on earlier input copies it to the prompt. Long output is squeezed into a button; double-click the button to expand it, or use its context menu to copy or view the text.

User code runs in a separate process. It is started again for each Run Module and with Restart Shell, so that every run begins with a fresh namespace.

>>> print("Hello")
Hello

Command line

python -m idlelib [-e] [-i] [-n] [-d] [-s] [-t title] [file ...]
python -m idlelib (-c command | -r script | -) [arg ...]

Use -h for a description of the options.

Startup failure

IDLE and the process running user code communicate through a local socket. A firewall, a broken network configuration or a file in the current directory with the name of a standard module (for example random.py) can prevent the start. Configuration files with errors are set aside and reported.
